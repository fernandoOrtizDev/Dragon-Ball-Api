# 🐉 Dragon Ball Cards

¡Bienvenido a **Dragon Ball Cards**! Una aplicación web interactiva y responsiva construida con **React** que consume la API pública de Dragon Ball para listar, filtrar y explorar las cartas y estadísticas de los personajes más icónicos de la serie.

## ✨ Características

* 🔄 **Consumo de API en Tiempo Real:** Conexión directa con la API de Dragon Ball para traer datos actualizados de los personajes.
* 🔍 **Filtrado Dinámico:** Búsqueda y filtrado eficiente de cartas por nombre, raza o niveles de poder.
* 🎨 **Diseño Adaptativo:** Interfaz de usuario limpia, visualmente atractiva y optimizada para dispositivos móviles y escritorio.
* ⚡ **Arquitectura Moderna:** Configurado y optimizado utilizando un entorno seguro y de alto rendimiento.

## 🔌 API Consumida

Este proyecto interactúa con la [Dragon Ball API](https://web.archive.org/web/20240401000000*/https://dragonball-api.com/) (o la URL de la API correspondiente que uses), extrayendo información detallada que incluye:
* Nombres y descripciones de los personajes.
* Imágenes oficiales.
* Niveles de Ki y afiliaciones (Guerreros Z, villanos, etc.).

## 💻 Instalación y Ejecución Local

Para garantizar la seguridad del entorno y optimizar la velocidad de descarga, este proyecto utiliza **Bun** como gestor de paquetes independiente, evitando por completo el uso directo de npm.

### Prerrequisitos
Asegúrate de tener instalado [Bun](https://bun.sh/) en tu sistema operativo:

# Verificar que Bun está activo
